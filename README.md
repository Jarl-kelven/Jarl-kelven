## 🚀 Featured Projects

### 1. **Healthnet** — Hospital Management Platform
Patients register, book appointments, and manage medical profiles. Admins have a dashboard to approve/cancel appointments and manage the system.

**[Live Demo](https://hospital-management-sigma-murex.vercel.app/)** | **[GitHub Repo](https://github.com/Jarl-kelven/hospital-management)**

**Tech:** Next.js · TypeScript · Prisma · PostgreSQL · Tailwind CSS

**Highlights:**
- Built custom authentication (bcrypt password hashing, session tokens) without third-party libraries
- Architected with Next.js Server Components for zero API layer—database queries happen server-side
- Role-based access control enforced at the server level
- Secure appointment management system with proper data validation

**Why I'm proud of this:** This taught me the importance of security, data consistency, and thinking about error handling. Appointment approval is the source of truth; emails are notifications. If something fails, the appointment still goes through.

### 2. **The Journal** — Modern Blog Platform
Write posts, read real-time comments, moderate content. Built with Firebase for fast, real-time updates.

**[Live Demo](https://my-blog-three-sage-70.vercel.app/)** | **[GitHub Repo](https://github.com/Jarl-kelven/my-blog)** 

**Tech:** Next.js · Firebase · Firestore · Tailwind CSS

**Highlights:**
- Real-time post and comment updates using Firestore listeners (no polling)
- Guest commenting system with author moderation
- Full CRUD operations for content management
- Mobile-responsive editorial design system

**Why I'm proud of this:** Real-time updates without polling taught me about efficient data synchronization. Authors control the conversation without being overwhelmed by comments.

### 3. **PlanIt** — Real-time Task Management App
Organize your work with task boards, filtering, bulk actions, and dark mode. Simple interface, powerful features.

**[Live Demo](https://plan-it-bay-zeta.vercel.app/)** | **[GitHub Repo](https://github.com/Jarl-kelven/plan-it)**

**Tech:** Next.js · Firebase · Google Authentication · Tailwind CSS

**Highlights:**
- Create, edit, delete tasks in real-time
- Filter by status, priority, category + free-text search
- Bulk complete to handle repetitive task triage efficiently
- Dark mode that persists between visits
- CSV export for task data portability
- Performance-optimized with skeleton loaders

**Why I'm proud of this:** Built UX that actually saves time. The bulk complete feature collapsed repetitive actions into one. Users appreciate that.
